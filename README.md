# Practiice

Adidas Sales Analysis (2020–2021)

## Project Overview
This project focuses on analysing Adidas sales data from 2020 to 2021 using Microsoft Excel.

The goal is to explore sales performance, identify business trends, evaluate product and retailer performance, and generate actionable insights that can support better business decisions.

## Business Objectives
- Evaluate overall sales performance.
- Identify top-performing products and retailers.
- Analyse sales performance across different regions.
- Understand sales trends over time.
- Evaluate operating profit and profit margins.
- Compare the performance of different sales methods.

## Dataset Description
The dataset contains sales transaction records with the following columns:

| Column | Description |
|---|---|
| sales_id | Unique sales transaction identifier |
| retailer | Name of the retailer |
| retailer_id | Retailer identification number |
| invoice_date | Date of transaction |
| region | Sales region |
| state | State where the sale occurred |
| city | City where the sale occurred |
| product | Product sold |
| price_per_unit | Price of each unit |
| units_sold | Number of units sold |
| total_sales | Recorded total sales |
| operating_profit | Recorded operating profit |
| sales_method | Method used to make the sale |

## Business Questions
The analysis seeks to answer the following questions:

1. What is the total revenue generated between 2020 and 2021?
2. Which region generated the highest sales?
3. Who are the top 10 retailers by total sales?
4. Which products generated the highest revenue?
5. What is the monthly sales trend?
6. Which sales method generated the highest revenue?
7. Which sales method sold the highest number of units?
8. Which product generated the highest operating profit?
9. Which region has the highest operating profit margin?
10. How does operating profit compare across retailers?
11. Which retailers contributed the most to overall sales?
12. Are there noticeable sales trends between 2020 and 2021?
